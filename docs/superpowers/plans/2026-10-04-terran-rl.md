# Terran RL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make headless Terran macro learning, measured evaluation, and Linux replay viewing reproducible.

**Architecture:** Keep BurnySC2 for game execution and use an in-process NumPy learner for the first experiment. Separate observations, policy decisions, and execution primitives; save checkpoints and replay/result receipts. Render replays after simulation using SC2's API and existing OSMesa/ffmpeg.

**Tech Stack:** Python 3.12, uv, BurnySC2 7.1.1, NumPy, unittest, Pillow, ffmpeg.

**Spec:** `docs/terran-rl-experiment.md`

## Global Constraints

- No sudo or large downloads.
- No deletion or relocation of sibling repositories, old checkpoints, logs, replays, or game data.
- Work in `.worktrees/terran-rl` on `Sam-v6/terran-rl`.
- Terran macro decisions must come from a learned policy.
- This is an explicit first experiment, not the final observation representation or action space.

## Review Focus

- Worktree paths and import ordering must not silently point at a nonexistent game installation.
- A callback failure, engine failure, or timeout must never be recorded as a training defeat or win.
- Mask illegal actions while retaining wait; train only on the action actually selected.
- Frozen evaluation and resume must preserve parameter and RNG/checkpoint integrity.
- Replay export must use the matching game build/map and fail on missing frames or encoder errors.

```python
def test_frozen_evaluation(self):
    before = policy.parameters.copy()
    policy.act(observation, legal_mask, explore=False)
    np.testing.assert_array_equal(policy.parameters, before)

def test_legal_wait(self):
    mask = np.zeros(policy.action_count, dtype=bool)
    mask[WAIT] = True
    self.assertEqual(policy.act(observation, mask, explore=True), WAIT)
```

# Execute human-ranked production requests

This plan is conditional on independent verification of the frozen precedence
fit's offline gates. Count weights and scripted assistance stay unchanged. RL is
off. The comparison uses the failed canary's AcropolisLE/Zerg/VeryEasy/Macro job,
seed816003,240game seconds and180wall seconds, with a fresh output directory.

Maintain one unissued intent per production family. Admit only from positive
count proposals after queued/pending accounting. Each intent has immutable ID,
admission loop and expiry1008loops later. Later zero forecasts do not erase it.
Execution iterates intent families, not only the latest forecast keys.

Submission binds an actor without creating another intent. Rejection, actor loss
or128-loop unobserved acknowledgement timeout releases that actor but retains the
same intent and expiry. An observed native order consumes the intent; admission
of another same-family intent requires a later observed start and current positive
surplus. Queued trains/upgrades count toward future birth/completion labels;
existing building foundations do not count toward future construction starts.
Expired intentions are explicitly logged and require a later zero-to-positive
proposal transition before rearming; deadlines never reset indefinitely.

Recompute mean symmetric pairwise win probability on current observations for
candidate families. Sort these scalar scores deterministically; do not sort with
a nontransitive comparator. Record scores and candidate identities. Missing
prerequisites, busy actors and supply shortage are structural blocks. They must
not reserve resources or invent prerequisites. An ignore-resources ability query
alone is not proof that supply requirements are satisfied.

The highest-ranked structurally feasible intent reserves its mineral/gas cost;
lower choices may spend only surplus. Reserve an unaffordable high-priority cost
without issuing an invalid action. If physical placement is impossible, release
that reservation for this batch and log the block. Keep command actor protection,
placement validation, native acknowledgements and between-forecast combat.
Record every admission, retry, expiry, observed order, priority, resource
reservation and proposed/selected command so attribution remains explicit.

Meaningful tests: forecast disappearance, repeated workers, duplicate building
proposals, rejected actions, actor loss, unobserved timeout, immutable expiry and
rearm, missing prerequisites/supply, shared actors, queue/start distinction,
symmetric ranking and the85mineral100Depot/75Refinery spending case. Pure test
fixtures may supply learned scores; they must not hardcode those priorities in
the live implementation.

Predeclared native engineering gate: observed Barracks start by90game seconds,
at least4military births and20livingworkers by240seconds, no duplicate intent
execution, and trace accounting independently verified. Native action acceptance
alone is insufficient. An intentional horizon cutoff is not a win. A short
engineering gate does not establish broad micro transfer or unlock RL.

If this gate passes, freeze six fresh all-race Rush/Macro development games.
Measure sustained production, action errors and actual outcomes. Preserve all
failures and stop unchanged repetition. Full broad human command control,
learned attack/micro, reliable learned Hard wins, higher difficulties and eventual
RL remain requirements of the original goal.

# Next experiment: human timing, professional production choice

The hypothesis is that when to make a production decision transfers across human
skill levels more reliably than which production action to choose. Test it once,
with independently verified labels and native effects. This is explicitly mixed
source imitation, not professional timing imitation or completion of the roadmap.
RL remains gated on useful native imitation.

## Freeze this experiment before fitting

1. Reconstruct actual 44-loop snapshots for the existing native teaching and
   diagnostic games. Preserve whole-game roles, named-player separation and
   reserved games. Audit original production ability identity, command issuance,
   engine repeats and unresolved events before labeling waits. The old
   target/queue-only issued matcher is insufficient ability proof. Unsupported
   windows remain censored. Do not infer human production from eventual births.
2. Train a current-state timing component on the Masters teaching games with
   natural class frequencies and equal game weighting. Predict whether a human
   production command occurs within 44 loops. Use a separate named-player
   calibration split and evaluation split; reused diagnostics must be declared.
   Require Brier improvement over the teaching event-rate baseline, event-level
   precision and recall at least 50%, predicted event frequency within 20% of
   observed frequency, and separately report quiet-window false positives.
3. Freeze that component and its encoder. Fit a separate professional production
   choice component on the 1,267 distinct verified teaching production events,
   using their own pre-command states. Reconcile the exact count and source
   identities before fitting. Do not multiply events through future windows or
   copy future actor/target arguments into current observations. Use the existing
   rich masked current-state encoder. Combined exposure ceiling: 101,940 example
   presentations, one fixed configuration, no sweep.
4. Evaluate professional choice on the existing three diagnostic games. Require
   nonworker event recall at least ten percentage points above both the teaching
   family prior and old checkpoint, plus correct production-building choices in
   every game. Report quality before legality masking separately. Audit live
   versus both source domains, including resources, queues, capacity and missing
   fields. Failure stops the fit; no extra epochs or native rollout.
5. Transfer verified reactive supply and scouting into the broad primitive adapter
   before native comparison, keeping their decisions fixed and separately logged.
   Every 44 loops, a positive gate ranks professional production choices. Native
   legality, current costs and pending requests determine executable candidates.
   Submit one request and reobserve. No forecast quotas, fixed human timeline or
   scripted worker/army/building priority. Broad raw controls remain available.
6. If both supervised gates pass, one 240-second native canary must produce an
   actual Barracks by 90 seconds, 20 living workers and four military births through
   learned production decisions. Then three frozen 600-second VeryEasy games,
   one per race, must yield actual wins. Cutoffs do not count. Diagnose the first
   divergence as timing, choice or execution before changing the system.

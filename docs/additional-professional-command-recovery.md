# Additional professional command recovery

The current six-game production-choice teaching set omitted five professional
games already acquired and used in an older broad-controller experiment. They
are additional teaching variety for the current choice model, not new downloads,
fresh evaluation games or a fully observed replay source. This preparation used
no model fitting, native game, RL, GPU, engine install or network transfer.

Apply the same conservative repeat recovery as the existing nine-game cohort:
require an original command-manager event, unchanged known selection, actual
owned actor identity/type and a unique unused converted action at the same loop.
Keep uncertain selection contexts unknown. Preserve all original labels and
owned/neutral observations, player statistics and map fields. Reconstruct enemy
visibility and memory causally from every chronological source frame, including
frames without an accepted command.
